# G119 游戏背景与分析口径

本文件直接提供项目背景；阶段范围见 `version-scope.md`，本轮实现仍查冻结仓库。

## 1. 游戏是什么

G119（破碎之地）是微恐、黑暗童话基调的**合作PVE搜打撤**。玩家探索地宫，搜集回收物，使用吸灵器与场景互动，战斗或躲避怪物，撤离并结算收获。M5以单人/四人合作为典型体验，这不是未来所有玩法的人数上限。

吸灵器参与搜刮、解谜、拉拽、抓取和战斗辅助；灵宠、角色技能、道具、负重与怪物压力共同影响探索。局外购买、维修、配装、成长解锁、图鉴、鉴定服务下一局。

## 2. 用业务链解释变化

| 改动 | 先查关联 | 给读者说明什么 |
|---|---|---|
| 回收物价格/品质/检视 | 投放、物品双键、计价、结算、图鉴/鉴定 | 能否正确估值、出售、展示；留空不直接等于0 |
| 奖励模式 | 具体玩法/条件/档位、物品名称和用途、数量与到账 | 哪个玩法可能发错/少发/无法领，不用数字大小比较不同资产 |
| 等级/解锁 | 仍引用的展示ID、兜底、入口条件 | 升级是否空白提示或入口不能用，而不是只说“外键断裂” |
| 地图/难度/Loot | 副本→地图→难度→布局→点位/模板→物品 | 是否进错地图、缺容器、错误掉落、影响撤离目标 |
| 技能/怪物/吸灵器 | 使用者、动作/特效/技能消费、多人状态 | 哪种操作或行为可能失效；冷却减少不证明总输出必然等比增加 |

## 3. 阶段与状态

**M5已完成，M6当前开发。** M5背景不是所有条目始终不变的保证；M6同时有一期完成、联调、资源替换与后续计划，不给整个系统贴“未接入”标签。

旧知识“商业化整体未接入”“检视表始终为空”“在建内容不该生效”不能继续当现行事实。商城、鉴定、救援、UGC等逐项查冻结实现与开关。

## 4. 知识的适用边界

- 人数、局长、地图数量可能随阶段变化，不把历史体验参数当本轮配置阈值。
- 本包的开发范围不单独证明某条代码已接入或实际开放。
- 本包提供的结构、消费方和测试入口要对齐冻结提交。没有CfgMod不等于无读取，可能通过统一路由、直接_cfg或生成表访问。
- 玩家反馈用于选场景，不等同本轮缺陷；AI归纳的评价不能作人数/比例统计。
- 发布流程、批准的经济指标、当前物品全量价格不在本文件中，缺少时索取或说明，不能补造。
