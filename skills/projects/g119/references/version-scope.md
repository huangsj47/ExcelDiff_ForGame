# 阶段基线与当前开发范围

**M5已完成，M6是当前正在开发的内容阶段。** 阶段用于理解玩法背景，不自动证明某条配置已启用或某项功能已部署。

## 1. M5已完成的基础体验

主循环包含局外购买/出售、角色与Ash、道具/负重背包、推荐套装、维修、怪物与回收物图鉴、局外鉴定、组队聊天、仓库道具栏与拾取替换；局内包括新手教学、多难度副本、玩法房和异步传送等。具体玩法仍可能在M6调整，不能把旧人数、时长、地图数量当永久硬规则。

## 3. 不再沿用的旧判断

- **死亡/救援**：早期关闭倒地的规则不适用于所有当前模式；M6正在制作倒地救援、爬行与复活。核查当前状态机和入口，不要求回退旧方案。
- **鉴定**：M5基础体验是局外鉴定，M6仍在迭代。局内入口出现时先确认当前设计和实现，不能直接判残留或功能重新启用。
- **商城/检视**：曾经无CfgMod/空表不代表当前未接。检查冻结表、生成路由和调用点，不能凭旧扫描排除风险。
- **人数/数值**：典型四人协作不自动否定新玩法8人；历史价格、负重和局长不自动约束当前玩法。

本包已提供项目背景，无需索取外部规划文件。需要判断本轮是否接入/开放时，读取本次冻结配置、代码和开关。开发未完成本身不是缺陷；有可达入口及具体异常才报告玩家风险，未知部分列为可操作核查点。
