口径说明

  • 「命中缓存」指上游 provider 报的 prompt cache 命中 token，不是平台自己的工具结果缓存。两者在表里分列显示，名字也分开。
  • 「未上报」与 0 是两件事。上游没回缓存字段时显示「未上报」，命中率一栏留空 —— 那表示未知，不是「一次都没命中」。
  • 费用是估算。接口只回 token 数、不回金额，金额按价格表算；没配价格表时这一列不显示数字。改价格表不会改历史金额的展示口径：金额一律按当前价格表重算，并在逐次明细里注明该次落库时的价格表版本。
  • 只统计新数据。这个功能上线前的运行没有采集过用量，明细里显示「本次用量未采集」，不显示 0。
  • 「输入 token」是每轮提示词的累计值：每一轮都会把上一轮的上下文重发一遍，所以轮次越靠后越贵。逐轮明细里能看出钱花在第几轮。
